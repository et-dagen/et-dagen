# Security

## Reporting a vulnerability

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/et-dagen/et-dagen/security/advisories/new).
Only the maintainers can see the report.

Do not open an issue or pull request, comment on one, or write on the wiki about it: this repository
and its wiki are public.

Include what you found, how to reproduce it, and what an attacker could do with it. You will get a
reply from the IT group of the E&T-dagene committee. The group changes every year, so allow a few days
in exam periods and over the summer.

## Scope

The website at etdagen.no, its API, and the code and workflows in this repository. The generated
documentation at docs.etdagen.no is in scope too, but publishing an endpoint there is not a
vulnerability on its own; the authorization check in each handler is what protects it.
